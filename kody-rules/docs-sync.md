# 规则:API/接口改动必须同步文档与注释

**适用范围**:公共 API、导出函数、路由/控制器、`README`、`docs/**`

**规则(大白话)**:
当 PR 改变了公共函数签名、导出接口、CLI 参数或 HTTP 路由,检查:
1. 函数/方法上的 doc 注释是否同步更新(参数、返回值、副作用);
2. 相关 `README` / `docs/**` 是否需要更新;
3. 若有 OpenAPI/schema,是否同步。
不一致则报 **Medium**,列出"代码已改但文档/注释未改"的具体位置 + 建议补什么。

> 对应诉求:文档/注释保持更新。低难度任务,可派给 `reviewer-light`(8B)并行处理省内存。
