# 规则:改了代码必须有对应测试

**适用范围**:`src/**`, `lib/**`, `packages/*/src/**`(按你的项目结构改)

**规则(大白话)**:
当一个 PR 修改或新增了 `src/` 下的函数/方法,但同一 PR 没有新增或修改对应的测试文件(`*.test.*` / `*.spec.*` / `tests/**`),则报告 **High**:指出哪些改动缺测试,并建议补哪一类测试(单元 / 集成 / E2E)。

**例外**:纯注释/文档改动、纯格式化、`*.config.*`、生成代码不要求测试。

> 对应诉求:单元/E2E 测试完整性。确定性层的"覆盖率 diff"先给硬证据,本规则让模型据此提出可操作建议。
